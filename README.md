
# SmartMart — DSA-Based Supermarket Billing System

A C++ Data Structures and Algorithms course project
to develop a web-based supermarket billing and inventory
management system.

## Project Objectives

- Manage supermarket products and inventory.
- Generate bills and receipts.
- Manage customer checkout queues.
- Demonstrate practical applications of DSA.
- Store product and transaction records using C++ file handling.
- Build a browser-based interface connected to a C++ backend.

## Technology Stack

- C++
- HTML
- CSS
- JavaScript
- Git and GitHub
- C++ file handling
